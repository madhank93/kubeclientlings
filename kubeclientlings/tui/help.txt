KEYS

  ↑ ↓ / k j    move between exercises
  ↵            run the current exercise
  e            open it in $EDITOR, then re-run on exit
  h            hint
  x            explain — the teaching walk-through for this exercise
  c            chapter — the long-form walk-through for this topic
  r            reset the exercise to its starting state
  n            jump to the next unsolved exercise
  /            search        esc  clear
  esc          cancel a wedged run
  ?            this help     q    quit

WHILE A RUN IS GOING

  The badge next to the exercise name shows a spinner and the elapsed time. A
  run against a live cluster can be slow for reasons that have nothing to do
  with your code, so watch the seconds rather than the spinner.

  esc cancels the run without killing the terminal.

LEARN SECTION

  When an exercise passes, a "Learn:" walk-through appears under the output —
  the fixed code, why it works, the detail that bites people, and links to the
  client-go docs. Press x any time to show or hide it.

  c opens the topic's chapter instead: one document explaining the machinery
  behind every exercise in the topic. It is the same README.md the topic
  directory carries, so it is one document, not a copy per exercise.

SAVING A FILE RE-RUNS IT

  The watcher re-verifies on every save, so the loop is: edit, save, watch the
  badge.
